# Resume parsing and ranking API

**Client:** a US recruiting agency  
**Industry:** HR / Recruiting  
**Year:** 2024

## The problem
Recruiters read 300 CVs per role to shortlist ten.

## What I did
Built an extraction model for skills, titles and dates plus a ranking model trained on past shortlists, served behind an async API that processes uploads in the background.

## Outcome
Shortlist overlap with senior recruiters reached 78%; screening time per role halved.

**Skills:** Natural Language Processing, API, Python, Machine Learning Model
