# Model deployment and monitoring on AWS

**Client:** a German insurtech  
**Industry:** Insurance  
**Year:** 2024

## The problem
Data scientists' models lived in notebooks and could not be called by the claims system.

## What I did
Containerised three models behind a versioned API on ECS with drift and latency monitoring.

## Outcome
p95 latency of 120 ms; deployment time for a new model version dropped from days to under an hour.

**Skills:** Amazon Web Services, Docker, Machine Learning Model, API
