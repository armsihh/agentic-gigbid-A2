# Appointment booking platform

**Client:** a chain of physiotherapy clinics  
**Industry:** Healthcare  
**Year:** 2023

## The problem
Receptionists booked by phone and double-bookings happened weekly.

## What I did
Built a booking web app with calendar slots per therapist, SMS/email reminders sent by a background job queue, and an admin view.

## Outcome
No-shows fell 38%; double bookings went to zero.

**Skills:** React, Node.js, MongoDB, API Development, Web Development
