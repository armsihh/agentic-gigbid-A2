# Third-party API integration hub

**Client:** a US dental practice software vendor  
**Industry:** Healthcare  
**Year:** 2025

## The problem
Each new insurer or lab integration took weeks and failed silently.

## What I did
Built an integration hub with adapters per partner, retries with backoff, idempotency keys and a dead-letter queue.

## Outcome
New integrations now take 3-4 days; silent failures eliminated.

**Skills:** API Integration, Node.js, TypeScript, RESTful API
