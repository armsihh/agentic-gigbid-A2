# Custom Shopify storefront features

**Client:** a skincare brand in Canada  
**Industry:** E-commerce  
**Year:** 2024

## The problem
The brand wanted a skin-quiz that recommends products and a bundle builder.

## What I did
Built a quiz and bundle builder as theme app extensions calling the Storefront API.

## Outcome
Quiz takers converted at 6.1% versus 2.4% site average.
