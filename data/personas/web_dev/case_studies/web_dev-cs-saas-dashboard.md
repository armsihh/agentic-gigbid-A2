# Multi-tenant SaaS admin dashboard

**Client:** a US property-management startup  
**Industry:** Real Estate  
**Year:** 2024

## The problem
Property managers used five spreadsheets to track units, tenants and maintenance.

## What I did
Built a Next.js dashboard with role-based access, tenant isolation in every query and server-side pagination.

## Outcome
Onboarded 60 property companies in four months; page loads under 1.2 s at p95.

**Skills:** React, TypeScript, Next.js, PostgreSQL, Web Application
