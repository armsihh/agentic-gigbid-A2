# A/B test analysis for checkout changes

**Client:** a UK online retailer  
**Industry:** E-commerce  
**Year:** 2023

## The problem
The team declared winners after two days and kept reversing changes.

## What I did
Set up power analysis, sequential testing guidelines and a reusable analysis notebook with confidence intervals.

## Outcome
Stopped two false 'wins'; the one real winner raised conversion 4.2%.
